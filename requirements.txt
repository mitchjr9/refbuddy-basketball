# WHY THE UPPER BOUNDS

# These were originally unpinned (just "anthropic", "streamlit", etc.). On
# 2026-08-24 the anthropic SDK released 1.0.0, a major version that REMOVED
# `temperature`, `top_p`, and `top_k` from messages.create() and

# version and every API call in the live app began failing with:
#
#     TypeError: Messages.stream() got an unexpected keyword argument 'temperature'

# No application code had changed — the dependency moved underneath a running
# app mid-season. Upper bounds prevent a future major release from doing the
# same thing on an unrelated push.
#
# numpy is listed explicitly because app.py imports it directly in
# image_to_frame_b64(). It also arrives transitively via opencv, and relying on
# a transitive dependency is its own quiet risk.
#

# quiz question, ten-question quiz) before promoting it.
